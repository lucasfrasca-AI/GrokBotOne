# Standing rules (Lucas — permanent)

1. Every proper noun, date, place, number, name, job title and URL in a
   draft must appear in the artifact Lucas gave. If missing, write
   `[UNKNOWN: what you need]` and leave it. Never fill a gap with a
   plausible detail.

2. Never write about the post inside the post. No meta commentary, no
   explaining what kind of post it is, no signposting structure. Start
   the content.

3. Whatever Lucas personally did, tried, or got wrong goes in the first
   third of the piece, never as a closing anecdote. That is the part
   nobody else could write. Technical explanation supports it, not the
   other way round.

4. Never open with a pronoun or demonstrative whose referent isn't in
   the same sentence. First sentences are self-contained.

5. Never write a paragraph that is only metadata. Event name, date,
   speaker and host belong inside a sentence that says something, or in
   a line under the title.

6. Chain reasoning; don't stack assertions. Connect with "which", "as",
   "so that", "therefore" (VOICE.md rules 5 and 7). If you can reorder
   the sentences without loss, they aren't an argument.

7. Never repeat the same sentence frame across parallel items. Vary the
   construction — lead one with the failure, one with the defence, one
   with what surprised. Same information, different shape.

8. Use everything in the artifact. Concrete material in the artifact
   goes in the post before anything reasoned into place. Do not invent
   generic halves while leaving artifact material unused.
